# พรอมป์ต์ตั้งต้นสำหรับ SME และฟรีแลนซ์

ชุดคำสั่งสั้น ๆ สำหรับร่างข้อความและตรวจข้อมูลก่อนนำไปใช้ ปรับข้อความใน
วงเล็บเหลี่ยมให้ตรงกับงานของคุณ

## ก่อนวางข้อมูล

- ใส่เฉพาะรายละเอียดที่จำเป็น และใช้ข้อมูลที่ตรวจสอบแล้ว
- อย่าวางรหัสผ่าน กุญแจ API ข้อมูลบัญชี หรือเอกสารภายในที่ไม่ได้รับอนุญาต
- แทนชื่อ เบอร์โทร อีเมล ที่อยู่ เลขบัญชี และข้อมูลลูกค้าด้วยป้ายทั่วไป
  เช่น [ลูกค้า A] หรือใช้ข้อมูลสมมติ
- ตรวจนโยบายการใช้ การเก็บ และการลบข้อมูลของเครื่องมือก่อนส่งข้อมูลจริง
- อ่านทวนผลลัพธ์ ตรวจข้อเท็จจริง และขออนุมัติก่อนส่งหรือเผยแพร่

## กรอบคำสั่งที่ใช้ร่วมกัน

ใส่กรอบนี้ต่อท้ายงานใดก็ได้:

    ใช้เฉพาะข้อมูลในหัวข้อ “ข้อมูลที่ยืนยันแล้ว” ห้ามแต่งข้อเท็จจริง
    ราคา วันที่ เงื่อนไข รีวิว หรือผลลัพธ์ขึ้นเอง แยกข้อเท็จจริงออกจาก
    ข้อเสนอแนะ หากข้อมูลไม่พอให้ถาม หรือทำเครื่องหมาย [รอตรวจสอบ]
    เขียนเป็นภาษาไทยโทน [ระบุโทน] สำหรับ [ผู้อ่าน] ในรูปแบบ [รูปแบบ]
    ปิดท้ายด้วยรายการจุดที่เจ้าของข้อมูลต้องตรวจทาน

## ร่างคำตอบจากข้อมูลบริการ

    ช่วยร่างคำตอบสำหรับคำถามนี้ โดยไม่เพิ่มนโยบายหรือคำมั่นที่ไม่ได้ให้ไว้
    คำถามลูกค้า (ตัดข้อมูลระบุตัวบุคคลแล้ว): [สรุปคำถาม]
    ข้อมูลบริการที่อนุมัติให้แจ้ง: [รายละเอียด]
    สิ่งที่ยังไม่ทราบหรือห้ามยืนยัน: [รายการ]
    ช่องทางและโทน: [ระบุ]
    ส่งร่างคำตอบพร้อมแยกรายการข้อมูลที่ต้องให้ผู้รับผิดชอบยืนยัน

## ทำโพสต์จากข้อเท็จจริง

    จากข้อมูลที่ยืนยันแล้ว ช่วยร่างโพสต์สั้นสำหรับ [ช่องทาง]
    เรื่องที่ต้องการสื่อ: [หัวข้อ]
    ข้อเท็จจริงที่ใช้ได้: [รายการ]
    ข้อจำกัดหรือข้อความที่ไม่ให้ใช้: [รายการ]
    เสนอหัวเปิดและเนื้อหาที่อ่านง่าย โดยผูกแต่ละข้อกล่าวอ้างกับข้อมูลข้างต้น
    ใช้คำชวนทำต่อเมื่อฉันระบุไว้เท่านั้น ห้ามสร้างรีวิวหรือรับประกันผล

## สร้าง FAQ จากเอกสารที่อนุมัติ

    ใช้เฉพาะข้อความต้นทางที่ได้รับอนุญาตด้านล่าง เพื่อร่าง FAQ สำหรับ [ผู้อ่าน]
    ข้อความต้นทาง: [วางเฉพาะส่วนที่จำเป็นและลบข้อมูลระบุตัวบุคคลแล้ว]
    ห้ามอนุมานนโยบายหรือเงื่อนไข หากต้นทางไม่มีคำตอบ ให้เขียน
    [ต้องถามผู้รับผิดชอบ] และระบุประเด็นที่ควรตรวจทาน

## ตรวจร่างก่อนส่งหรือเผยแพร่

    ตรวจร่างนี้เทียบกับข้อมูลอ้างอิงที่ยืนยันแล้ว
    ร่าง: [วางข้อความ]
    ข้อมูลอ้างอิง: [รายการหรือข้อความที่อนุมัติ]
    แยกข้อความเป็น “รองรับด้วยข้อมูล”, “ต้องยืนยัน” และ “ไม่มีหลักฐาน”
    เสนอคำแก้เฉพาะส่วนที่รองรับด้วยข้อมูล ห้ามเติมข้อเท็จจริงใหม่

ผลลัพธ์จาก AI เป็นเพียงร่างสำหรับตรวจทาน ไม่ใช่คำแนะนำด้านกฎหมาย ภาษี
หรือวิชาชีพ และไม่รับประกันความถูกต้องหรือผลลัพธ์ของงาน
