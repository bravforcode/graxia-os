# 1. Content Creation (Reels, TikTok, YouTube) — 30 Prompts

### P-CC-01: เขียน Hook แบบหยุดนิ้ว (Scroll-stopper)
**สถานการณ์**: ต้องเปิดวิดีโอสั้น 15-30 วินาที ให้คนหยุดเลื่อนใน 1.5 วิ
**Prompt**:
```
เขียน hook เปิดคลิปวิดีโอสั้น (15-30 วินาที) หัวข้อ "[หัวข้อ]" กลุ่มเป้าหมาย "[กลุ่มเป้าหมาย]"
โทน: [สนุก/จริงจัง/ช็อก]
ข้อกำหนด:
- ประโยคแรก ≤ 8 คำ ห้ามเกิน
- ใช้ตัวเลข ความเจ็บ หรือความขัดแย้ง
- เขียน 5 variations ให้เลือก
- แต่ละ variation บอกเหตุผลทางจิตวิทยาว่าทำไมน่าสนใจ
```
**ตัวอย่างผลลัพธ์** (หัวข้อ: "วิธีออมเงิน 1 หมื่น/เดือน"):
> 1. "เงินเดือน 15,000 ก็ออมได้ 1 หมื่น ถ้าทำ 3 ข้อนี้" (เหตุผล: ตัวเลขเฉพาะ + ความขัดแย้ง "15,000 vs 10,000")

### P-MC-01: เขียน Facebook Ad (ขายของตรง)
**Prompt**:
```
เขียน Facebook Ad copy ขาย [สินค้า] ราคา [ราคา]

```
