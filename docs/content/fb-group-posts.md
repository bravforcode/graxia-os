# เทมเพลตโพสต์ Facebook กลุ่ม + กระทู้ Pantip — Ai Factory

## เทมเพลตโพสต์ FB กลุ่ม (ให้ความรู้ → ลิงก์ในคอมเมนต์)

### โพสต์ 1: ให้ความรู้ (กลุ่มฟรีแลนซ์/AI)
```
[ให้ความรู้ ไม่ใช่โฆษณา]

หลายคนถามว่า "AI จะมาแย่งงานฟรีแลนซ์ไหม?"

ความจริง: AI แย่งงานคนที่ "ไม่ใช้ AI" ไม่ใช่คนที่ใช้เป็น
- งานเขียนคอนเทนต์: AI ช่วยร่าง 60% คนตรวจแก้ + เข้าใจแบรนด์ = 40% ที่สำคัญ
- งานแปล: AI แปลได้ แต่การปรับสำนวน/วัฒนธรรม = ยังต้องคน
- งานกราฟิก: AI สร้างได้ แต่การจัดวาง + เข้าใจโจทย์ = ต้องคน

ใครใช้ AI เป็นจะรับงานได้มากขึ้น ไม่ใช่น้อยลง
(มีตัวอย่างพรอมต์ที่ใช้จริงในคอมเมนต์ครับ)
```
**คอมเมนต์:** ลิงก์บทความ + ลิงก์สินค้า

### โพสต์ 2: ถาม-ตอบ (engagement)
```
โพลล์: ตอนนี้คุณใช้ AI ทำงานประจำวันไหม?
👍 ใช้ทุกวัน
❤️ ใช้บางงาน
😮 ยังไม่ได้ใช้ แต่สนใจ
🔥 ใช้ไม่ได้ผลเท่าที่ควร

(แชร์เคล็ดลับในคอมเมนต์ให้ทุกคน)
```

### โพสต์ 3: แจกของฟรี (lead magnet)
```
แจกฟรี! Checklist เปิดร้านออนไลน์ 30 วัน 📋

สำหรับคนที่อยากเริ่มขายของออนไลน์แต่ไม่รู้จะเริ่มจากตรงไหน
ครบตั้งแต่: เลือกสินค้า → ตั้งราคา → ถ่ายรูป → ลงขาย → โปรโมท

👉 ดาวน์โหลดฟรี: [ลิงก์หน้า lead magnet]
(ไม่มีค่าใช้จ่าย ไม่ต้องสมัครอะไรเพิ่ม)
```

## กระทู้ Pantip (ห้องเทคโนโลยี)

### กระทู้: "ใช้ ChatGPT ภาษาไทยยังไงให้ได้งานจริง (แชร์ประสบการณ์)"
```
สวัสดีครับ เพื่อนๆ สายเทคโนโลยี

ช่วงนี้เห็นหลายคนใช้ ChatGPT แต่ได้คำตอบกลางๆ ไม่รู้จะเอาไปใช้ยังไง
ผมเลยอยากแชร์วิธีที่ใช้จริงในงาน (เขียนคอนเทนต์ + ทำงานออฟฟิศ):

1. บอกบทบาทก่อนเสมอ เช่น "คุณคือนักการตลาด SME ไทย"
2. ให้บริบทเยอะๆ ยิ่งรู้จักงานเรา ยิ่งตอบตรง
3. ระบุรูปแบบ: "ตอบเป็น 5 ข้อ ภาษาไทย กระชับ"
4. ถ้าคำตอบไม่ดี บอกให้ปรับ ไม่ใช่เริ่มใหม่

ตัวอย่างที่ใช้จริง:
[วางตัวอย่างพรอมต์ 2-3 อัน + ผลลัพธ์]

ทุกคนมีเทคนิคอะไรแชร์กันได้ครับ เผื่อมีวิธีที่ดีกว่าที่ผมใช้อยู่
```
> กฎ: ห้ามใส่ลิงก์สินค้าในกระทู้ — ถ้ามีคนถาม "ใช้เครื่องมืออะไร/มีชุดพรอมต์ไหม" ค่อยตอบ + ลิงก์

## กฎการโพสต์กลุ่ม
- อ่านกฎกลุ่มก่อนโพสต์เสมอ (หลายกลุ่มห้ามโฆษณา)
- อัตรา: ให้ความรู้ 3 ครั้ง : โปรโมท 1 ครั้ง
- ตอบคอมเมนต์ทุกอัน — คนถาม = ลูกค้าใกล้สุด
- อย่าโพสต์ลิงก์ซ้ำในหลายกลุ่มพร้อมกัน (โดนแบน)
