## 5. การใช้เงิน (ถ้าระดมทุน)

**สมมติขอ 5M THB (~$150K) — runway 18 เดือน:**

| รายการ | จำนวน | % |
|---|---|---|
| Product (dev + LLM cost) | 2.0M | 40% |
| Sales & Marketing (pilot → 100 ลูกค้า) | 1.5M | 30% |
| Infra & Security (SOC2-ready) | 0.8M | 16% |
| Buffer | 0.7M | 14% |

**Milestone 12 เดือนหลังระดมทุน:**
- [ ] 100 ลูกค้า Standard + 10 Enterprise
- [ ] MRR 1M THB
- [ ] Churn < 3%
- [ ] 2 ช่องทาง marketplace เชื่อมจริง (Shopee + TikTok Shop)

---

## 6. Sensitivity (สิ่งที่ทำให้ตัวเลขพัง)

| ความเสี่ยง | ผลกระทบ | แผนรับมือ |
|---|---|---|
| Churn สูงกว่าคาด (10%+) | MRR ปี 3 ลด ~30% | enterprise focus, onboarding เข้ม |
| LLM cost พุ่ง | margin ลด 5-10% | local model (llama), caching, batch |
| CAC สูงกว่าคาด | คุ้มทุนช้าลง 6 เดือน | content marketing, affiliate แทน paid |
| ตลาด marketplace เปลี่ยน API | integration พัง | abstraction layer + sandbox testing |
