ลากปุ่มนี้ไป Bookmarks Bar

แล้วเปิด fastwork.co (login แล้ว) → คลิก bookmark ที่ลากไป → JWT จะถูกคัดลอกให้อัตโนมัติ

⚡ คัดลอก FastWork JWT

  1. ลากปุ่มดำด้านบนไป Bookmarks Bar (ถ้าไม่เห็น bar กด Ctrl+Shift+B)
  2. เปิด https://fastwork.co แล้ว login
  3. คลิก bookmark ⚡ คัดลอก FastWork JWT → จะขึ้น popup ให้คัดลอก
  4. วางค่าใน .env.local → FASTWORK_JWT=... แล้วรัน python automation/fastwork_poster.py --verify

* Bookmarklet ทำงานเฉพาะตอนอยู่บน fastwork.co เท่านั้น (อ่าน cookie ของเว็บนั้น)
